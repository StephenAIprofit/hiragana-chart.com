# Hiragana Chart

Live site: https://hiragana-chart.com/

A static Japanese learning site: Hiragana and Katakana chart, kana quiz, and Kanji translator.

## Pages

| Page | URL | What it does |
| --- | --- | --- |
| Chart | https://hiragana-chart.com/ | Basic 46, dakuten, yoon, sokuon, stroke order, audio, printable tables, confusable tables |
| Quiz | https://hiragana-chart.com/quiz | Characters and Words modes, L1–L4, Hiragana and Katakana |
| Kanji Translator | https://hiragana-chart.com/kanji-translator | Draw or type. English, Romaji, or kana to Kanji |

## Navigation

Desktop: Home | Chart ▾ | Quiz | Kanji Translator | Pronunciation | Printable table | FAQ.

Chart dropdown: Hiragana 46, Dakuten & Handakuten, Yoon, Katakana, Sokuon & Long Vowels, Stroke order.

## Chart page

The switcher changes the whole table between Hiragana and Katakana.

- Hero: "Learn all 46 Hiragana and Katakana" with a line for beginners.
- Detail panel is sticky. Three sample characters (あ か ん) sit inside the panel. Click one to load its stroke order and audio.
- Basic 46, dakuten, yoon, sokuon examples.
- Printable Hiragana chart and printable Katakana chart.
- Visual confusables and pronunciation confusables.
- Audio plays only when a character or sokuon example is clicked.
- Yoon shows the base character first, then the small kana at the bottom right.
- FAQ is a single section of common questions.

## Quiz page

- Characters mode: Romaji → kana, or kana → Romaji. Audio plays.
- Words mode: English word → kana. No audio. Each word once per round.
- L1–L4. Katakana at `?script=katakana`.

## Kanji Translator page

- Draw tab: write a Kanji. Handwriting recognition looks it up.
- Type tab: type English, Romaji, or kana.
- Results show Kanji, reading, and English. Exact English matches rank first.
