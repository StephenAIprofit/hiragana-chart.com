How to type Japanese with romaji

Most sounds are typed the way they are written in romaji: ka → か, shi → し, tsu → つ, kya → きゃ. These are the cases that catch people out:

Add a Japanese keyboard to your device

For everyday typing, including kanji, install the free Japanese input method that comes with your system. The menus can differ slightly between versions:

  • Windows: Settings → Time & language → Language & region → Add a language → Japanese.
  • Mac: System Settings → Keyboard → Text Input → Edit → + → Japanese – Romaji.
  • iPhone and iPad: Settings → General → Keyboard → Keyboards → Add New Keyboard → Japanese → Romaji.
  • Android (Gboard): Gboard settings → Languages → Add keyboard → Japanese.

The romaji rules above work the same way on all of them.

Keyboard questions

Can I type kanji with this keyboard?

No. It types hiragana and katakana only. Turning kana into kanji needs the large dictionary that a full Japanese input method has. To find out what a kanji means, draw it or type an English word in the kanji translator.

Why did こんにちは come out as こんいちは?

Because n followed by n makes ん, and the next i is read on its own. This is how Japanese keyboards on Windows, Mac, and phones work too. Type nn for ん when the next sound is a vowel, y, or n: konnnichiha gives こんにちは.

Is my text saved or sent anywhere?

Nothing is sent to a server. The text box keeps your text in this browser so it is still there if you reload the page. Press Clear to remove it.

Does it work on a phone?

Yes. Type romaji with your phone keyboard, or tap the kana keys below the text box. If your phone keeps capitalising the first letter, that letter turns into katakana; tap the kana keys or switch off auto-capitalisation.
