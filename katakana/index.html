General stroke order rules

Kana follow the same basic rules as kanji: write top to bottom, then left to right, and finish horizontal strokes before the vertical strokes that cross them. For dakuten, write the base character first and add the two dots last. For yoon, write the full-size character first and then the small ャ, ュ, or ョ in the lower right.
